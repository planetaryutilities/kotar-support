# Security Policy

We take security concerns involving **Starforge Kotar** seriously.

## Reporting a Security Vulnerability

**Do not report suspected security vulnerabilities through public GitHub Issues, Discussions, Wiki pages, or pull requests.**

Public disclosure may expose users or systems to unnecessary risk.

Please report suspected vulnerabilities privately using the designated Starforge security contact:

**Email:** security@YOUR-DOMAIN.example

Replace the address above with the appropriate security contact before publishing this repository.

---

## What to Include

When reporting a suspected vulnerability, please provide as much information as reasonably possible, including:

- Description of the vulnerability
- Affected Starforge Kotar version
- Environment in which the issue was observed
- Steps required to reproduce the issue
- Proof-of-concept information, where appropriate
- Potential impact
- Any known mitigations or workarounds
- Your contact information if you would like a response

Please do not include sensitive customer data unless specifically requested through an approved secure communication channel.

---

## Sensitive Information

Do not send the following through public GitHub infrastructure:

- Passwords
- Authentication tokens
- API keys
- Private keys
- Customer models
- Customer data
- Proprietary information
- Export-controlled information
- ITAR-controlled information
- Classified information
- Personally identifiable information

We may request additional information through an appropriate private channel during investigation.

---

## Responsible Disclosure

We ask security researchers and users to provide us a reasonable opportunity to investigate and address reported vulnerabilities before publicly disclosing them.

Where appropriate, we may coordinate disclosure timing with the reporter.

Submission of a security report does not create a contractual relationship or guarantee:

- A particular response time
- A particular remediation time
- Payment
- A bounty
- Public acknowledgement

Unless separately announced, Starforge does not operate a bug bounty program.

---

## Scope

This security policy applies to supported Starforge Kotar software and associated Starforge-operated services where applicable.

Third-party products, browsers, operating systems, hosting providers, plugins, libraries, or external services may be governed by their respective vendors' security policies.

---

## Supported Versions

Security updates are generally provided for versions of Starforge Kotar that are currently supported.

Specific supported-version information may be published separately in release documentation.

Users are encouraged to use a current supported release.
