# Starforge Kotar Support

Welcome to the public support and documentation repository for **Starforge Kotar**.

Starforge Kotar is a browser-based environment for working with SysML v2 models. This repository provides a public location for:

- User documentation
- User manuals and tutorials
- Frequently asked questions
- Troubleshooting information
- Bug reports
- Feature requests
- Documentation feedback
- Release information

> **Important:** This repository does not contain the Starforge Kotar source code.

Starforge Kotar is commercially distributed software and is not open-source software. Publication of this repository does not grant any license to the Starforge Kotar software.

## Reporting a Bug

If you encounter a problem with Starforge Kotar:

1. Check the Wiki and existing issues to see whether the problem is already documented.
2. Search existing GitHub Issues for similar reports.
3. If no existing issue applies, create a new **Bug Report**.

Please provide enough information to reproduce the problem, including where applicable:

- Starforge Kotar version
- Browser and browser version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant error messages or logs
- A minimal synthetic SysML v2 example

### Do not upload sensitive information

This is a **public repository**.

Do not include:

- Proprietary customer models
- Confidential information
- Export-controlled information
- ITAR-controlled information
- Classified information
- Credentials, passwords, tokens, or API keys
- Personally identifiable information
- Customer-sensitive datasets

When a model is required to reproduce an issue, please create a minimal synthetic example that demonstrates the problem without exposing sensitive information.

## Requesting a Feature

Feature requests are welcome.

Before submitting a request:

1. Search existing issues for similar requests.
2. Describe the problem or workflow you are trying to address.
3. Explain the desired behavior.
4. Include an example where useful.

Feature requests may be considered for future development but submission of a request does not imply a commitment to implement the requested capability.
